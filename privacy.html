Kebijakan Privasi — juna-backup Berlaku sejak 1 Oktober 2026. Halaman ini juga tersedia dalam bahasa Inggris secara ringkas di bagian paling bawah. 1. Siapa yang mengelola juna-backup adalah integrasi pribadi milik Untung Priyono. Integrasi ini bukan layanan publik dan tidak melayani pengguna lain. Penanggung jawab data: Untung Priyono, untungpriyono@gmail.com. 2. Data Google apa yang diakses Integrasi ini meminta izin Google Drive (cakupan penuh) hanya untuk satu keperluan: menulis dan membaca berkas cadangan milik pemilik akun itu sendiri di Google Drive-nya. Data yang disentuh adalah berkas cadangan yang dibuat oleh server pribadi pemilik akun (arsip basis data, arsip catatan agen AI, dan berkas pemeriksaannya). 3. Bagaimana data digunakan Mengunggah berkas cadangan dari server pribadi pemilik akun ke Google Drive pemilik akun yang sama. Membaca daftar berkas cadangan untuk keperluan pemeriksaan (apakah salinan terbaru lengkap). Menghapus berkas cadangan lama sesuai kebijakan penyimpanan yang ditetapkan pemilik akun. 4. Apa yang disimpan di server, dan bagaimana diamankan Server pribadi pemilik akun hanya menyimpan token akses yang diberikan Google agar pencadangan bisa berjalan otomatis. Token itu disimpan di berkas konfigurasi milik root pada server tersebut, tidak pernah ditulis ke dalam berkas cadangan, tidak pernah dicetak di laporan, dan tidak pernah dikirim ke pihak mana pun. Isi Google Drive tidak pernah disalin keluar dari Drive selain untuk memulihkan data pemilik akun sendiri. 5. Pembagian data ke pihak ketiga Tidak ada. Data Google tidak dijual, disewakan, dipakai untuk iklan, dipakai untuk melatih model kecerdasan buatan, maupun dibagikan kepada pihak lain. Tidak ada analitik pihak ketiga di halaman ini. 6. Retensi dan penghapusan Berkas cadangan disimpan di Google Drive pemilik akun dan dihapus menurut kebijakan penyimpanan yang ditetapkan pemilik akun. Token akses dapat dicabut kapan saja oleh pemilik akun melalui myaccount.google.com/permissions. Setelah izin dicabut, integrasi ini tidak lagi memiliki akses apa pun ke akun Google tersebut. Permintaan penghapusan data dapat dikirim ke alamat kontak di atas. 7. Perubahan kebijakan Bila cakupan akses atau cara penanganan data berubah, halaman ini diperbarui dan tanggal di bagian atas disesuaikan. 8. Kontak Untung Priyono — untungpriyono@gmail.com Ringkasan bahasa Inggris juna-backup is a private, single-user integration owned by Untung Priyono. It uses the Google Drive scope solely to upload, list, and rotate backup files created by the owner's own private server into the owner's own Google Drive. Google user data is never sold, shared, used for advertising, or used to train AI models. The only credential stored on the server is an OAuth token, kept in a root-only configuration file and excluded from all backups. Access can be revoked at any time at myaccount.google.com/permissions. Contact: untungpriyono@gmail.com.
